# Krolik Control 0.11.0-dev

Автор: LeemonSun. Приложение для настройки и проверки Windows 11 x64 с предусмотренными путями совместимости Windows 10 x64. Это кандидат для проверки на Windows: аппаратная совместимость ещё не подтверждена испытаниями на реальных ПК.

## Запуск из исходников

Для знакомства запустите "python main.py --demo" на Windows с Python 3.11+. Деморежим использует отдельные данные и не меняет настройки системы.

## Возможности

- «Мой ПК»: компоненты, память, диски, нагрузка, доступные датчики. NVIDIA NVML и AMD ADL читаются из установленного драйвера; собственный драйвер мониторинга не устанавливается. Недоступные температуры не подменяются догадками.
- Мониторы: определение режимов, частот, поворота и расположения; дополнительные схемы и доступный HDR/WCG. Перед изменением запускается отдельный процесс возврата изображения, в том числе при завершении основного приложения. Его Windows-поведение ещё требует аппаратной проверки.
- Звук: конкретные устройства, громкость и mute, тестовый сигнал, уровень микрофона, микшер сессий и возврат последней громкости. Переключение основного устройства экспериментальное: используется недокументированный интерфейс Windows с перечитыванием результата.
- Программы: каталог из 26 пакетов, установка после подтверждения, автоматическая подготовка официального компонента Microsoft при его отсутствии. Общий список установок из реестра и Microsoft Store, отдельные версии, удаление штатным деинсталлятором и восстановление MSI. Поиск обновлений охватывает каталог, а не все существующие программы.
- Драйверы: приоритетные категории устройств, поиск предлагаемых Windows Update пакетов, общая проверяемая копия сторонних драйверов перед обновлением. Наличие самого нового драйвера производителя для любого устройства не гарантируется.
- Автозагрузка: записи запуска и сторонние задания входа/загрузки. Для задач текущего пользователя предусмотрены подтверждение, проверка и возврат. Службы доступны для чтения.
- Файлы: карта выбранной папки, крупные файлы, дубликаты по SHA-256, проверка хеша, доступные владельцы блокировки; пакетное переименование с предпросмотром, журналом, возвратом и восстановлением прерванной операции. Автоматического удаления дубликатов нет.
- Система и сеть: процессы и соединения, цепочка DNS/TCP/TLS, потери и задержка до узла, Wi-Fi, батарея, состояние Defender, доступные NVMe SMART-показатели, принтеры и устройства, хронология сбоев. Результаты имеют явные ограничения, а не заключение «всё исправно» по отсутствующим данным.
- Проверка и исправление: звук, сеть, измерение скачивания и задержки, ограниченные исправления, базовые тесты CPU/RAM/накопителя/GPU, проверка памяти, запись кадров игры через PresentMon. Итоги сравнимы при одинаковой конфигурации и методике; универсального выдуманного балла нет.
- Перед переустановкой: экспорт читаемых настроек, списка программ и набора из каталога; заранее загрузить установщики в выбранную папку. Веб-установщикам может требоваться интернет; это не резервный образ Windows и не копирование личных данных.
- Тест устройств: клавиатура, мышь, геймпад, предпросмотр камеры и экранные заливки. Камера выключается при уходе; запись и отправка видео не выполняются.
- BIOS: чтение сведений и только перечисленных поддерживаемым OEM-интерфейсом настроек Lenovo/Dell/HP. Универсальная запись XMP/напряжений на произвольной ASUS/MSI/ASRock не реализована. Совместимость и фактическая запись на железе не проверены.
- Общий поиск, избранное, профили, светлая/тёмная тема, масштаб, навигация боковыми кнопками мыши. Шесть групп навигации; служебные данные раскрываются отдельно.

## Результаты и возврат

Неподтверждённое действие не становится зелёным успехом. Ожидание и исходный журнал сохраняются; повторная проверка только читает состояние, не повторяет команду. Для части параметров оболочки подтверждается сохранение значения, а визуальный эффект требует нового входа и проверки пользователем; такое ожидание можно закрыть отдельно. Возврат настроек проверяется; установка приложений и драйверов не объявляется универсально отменяемой.

## Исходники и сборка

Для запуска исходников нужен Python 3.11+: `python main.py --demo --no-browser` для демонстрации без изменений или `Start.cmd` на Windows. Демоданные изолированы от рабочего состояния.

Проверки: `python -B -m unittest discover -s tests`. Браузерные сценарии находятся в `tests/*ui.cjs` и `tests/lifecycle.cjs`; нужен Playwright и Chromium. Контрактные проверки установщика и OEM-интерфейсов используют PowerShell с подменами, не реальное оборудование.

Сборка: `python build_portable.py --output dist/KrolikControl --cache .portable-build/cache --zig /path/to/zig`. Закреплены Zig 0.15.2, Python 3.14.8 embed x64 и PresentMon 2.6.0 с SHA-256. Runtime включается локально. При наличии собственного сертификата доступны `--sign-tool` и `--certificate-thumbprint` на Windows; без них подпись не имитируется.

Готовый пакет содержит приложение, runtime, обязательные лицензии и данные проверки целостности. README, тесты, отчёты и средства разработки остаются в исходниках. Выполненные проверки описаны в `docs/TESTED.md`, незавершённая аппаратная приёмка — в `docs/WINDOWS-TEST.md` и `docs/ACCEPTANCE-1.0.md`. Исторические отчёты относятся к указанным в их имени версиям.
