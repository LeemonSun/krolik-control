# Проверки Krolik Control 0.10.0

20 октября 2026. Среда: Linux, Python 3.12.14, Chromium 131 / Playwright, PowerShell 7.6.7 и Zig 0.15.2. Windows EXE здесь не запускались.

## Выполнено

- 358 модульных/API-тестов — успешно. Это финальный прогон логики; до последних регрессий прошли прогоны на 355 и 356 тестов. Отдельные проверки используют реальные временные файлы и дочерний Python-процесс. Вызовы Windows и оборудования подменяются.
- 10 браузерных наборов — успешно: ui, care-ui, apps-ui, audit-ui, reliability-ui, lifecycle, pc-ui, firmware-ui, release-ui, product-ui. Общий сценарий открывает все 27 страниц, проверяет навигацию X1/X2, сохранение очереди/вкладок/поиска и фокуса. Проверки нового инструментария включают 14 групп пользовательских сценариев.
- После исправлений цвета таблиц и подписи возврата звука повторены затронутые product-ui/release-ui; дополнительно повторён общий ui. Таблицы проверяются в обеих темах с контрастом текста не ниже 4.5:1. Разные сценарии проверяют ширины 600–1600 px и масштаб 100–150%; это не аппаратный DPI-тест Windows.
- Синтаксис Python и 14 файлов JavaScript — без ошибок. Pyflakes для приложения и сборщика — без замечаний.
- Парсер PowerShell проверил 61 полный статический/составной сценарий — без ошибок. Разобран полный observe, а не отдельный фрагмент конкатенации. Парсер PowerShell 7 не доказывает выполнение всех модулей под Windows PowerShell 5.1.
- 15 сценариев Lenovo/Dell/HP — успех, блокировка, внешнее изменение, недопустимый выбор, отказ метода — прошли с CIM-двойниками.
- 4 сценария транзакции установщика с подменами реестра/COM — первая установка, очистка неудачной первой установки, возврат прежних файлов/значений/ярлыков при отказе обновления, отказ второго одновременного установщика.
- C-модули benchmark, memory, graphics и adl компилируются в Windows x64 с `-Wall -Wextra -Werror`. Это проверка сборки, не исполнение на оборудовании.
- Проверка выпуска сравнивает весь манифест, все упакованные модули Python/UI с текущими исходниками, содержимое ZIP с portable-папкой, точный payload и скрипт внутри Setup. Проверяется формат PE x64 всех EXE/DLL/PYD, закреплённые SHA-256 runtime и PresentMon, наличие лицензий и отсутствие документов/тестов/логов в готовой папке. Результаты — CHECKS-0.10.0.json и BUILD-0.10.0.json.

## Основные регрессии

Неподтверждённые результаты остаются отдельными от успеха и переживают перезапуск. Перечитывание обновляет исходную историю и не стирает новый, другой выбор. Повторное сохранение журнала сохраняет идентификатор действия. Повторный запуск неподтверждённой операции блокируется до проверки.

Возврат устройства звука читается из сохранённого журнала и недоступен при отключении/внешней смене устройства. Микшер проверяет актуальность сессии и возвращает прежнюю громкость. Выбор устройств и тест звука не сбрасываются при перерисовке.

Разные установки и версии программы не зависят от порядка реестра; общая HKCU-запись двух представлений не дублируется. Удаление/восстановление требует неизменившегося одноразового подтверждения. Установки не выдаются за автоматически отменяемые настройки.

Файловые инструменты не следуют ссылкам и не удваивают hardlink. Переименование имеет ограниченный асинхронный предпросмотр, исключает перезапись постороннего файла, проверяет личности файлов и сохраняет фазы транзакции. Проверяются частичный отказ, возврат и восстановление после расхождения счётчика журнала с фактическими именами. Дубликаты не удаляются автоматически.

Проверены отказ запуска защиты экрана до изменения, границы CCD-снимка, решения отдельного наблюдателя, устаревшие токены задач/микшера, остановка собственных файловых заданий, выключение камеры/опроса контроллера при уходе и истёкший старый таймер питания после нового запроса.

## Воспроизведение

```sh
python -B -m unittest discover -s tests
node tests/ui.cjs
node tests/product-ui.cjs
node tests/release-ui.cjs
python tests/firmware-contract.py /path/to/pwsh
PWSH=/path/to/pwsh python tests/installer-transaction.py
python build_portable.py --output /path/to/KrolikControl --cache /path/to/cache --zig /path/to/zig
python tests/validate_release.py /path/to/KrolikControl /path/to/cache
```

Для браузерных сценариев задайте CHROMIUM_PATH при нестандартном расположении Chromium. Остальные наборы — `tests/*ui.cjs` и `tests/lifecycle.cjs`. Снимки QA не включаются в дистрибутив.

## Что ещё не подтверждено

Реальные Windows 10/11: запуск Setup/EXE, обновление/удаление, UAC, WinGet/Appx с чистой ОС, Windows Update, Core Audio/PolicyConfig, дисплеи/HDR и возврат после убийства процесса, драйверы/датчики NVML/ADL, NVMe/USB/RAID, ETW/игры, права задач, сон/перезагрузка и OEM BIOS. Доступен сценарий чтения `tools/Check-Windows.ps1`; он также ещё не выполнялся на Windows и не заменяет приёмочную матрицу ACCEPTANCE-1.0.md.

Утверждения «все баги устранены», «95% любых настроек» и «стабильная 1.0» этими результатами не обосновываются. Собственные EXE не подписаны сертификатом; канал автоматических обновлений не развёрнут.
