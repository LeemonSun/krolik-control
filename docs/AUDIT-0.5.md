# Аудит Krolik Control 0.5.0

Дата: 18 октября 2026. Автор проекта: LeemonSun.

Исправления:

- Отсутствующий WinGet больше не делает каталог программ недоступным. Подтверждение включает установку официального компонента Microsoft и выбранных пакетов.
- Подготовка сначала проверяет доступный WinGet и установленный App Installer; загрузка нужна только при отсутствии рабочего компонента.
- Загрузки идут с фиксированных официальных узлов, проверяются размером и SHA-256 из HTTPS-метаданных стабильного выпуска. Пакеты проверяются по имени и издателю. Проверка подписи выполняется Windows; обход сертификатов и политик не используется.
- Выбираются зависимости x64/neutral; обход путей и неожиданные компоненты отклоняются. Временные файлы удаляются при успехе, ошибке и отмене.
- Ошибка подготовки пропускает зависимые установки. Остальные выбранные настройки могут завершиться; повтор подготовки доступен в результате и каталоге программ.
- Сетевой сбой при определении приложения не принимается за его отсутствие. После успешного установщика повторно проверяется наличие приложения. Отдельно обрабатываются отмена, необходимость перезагрузки, нехватка места и отсутствие подходящего обновления.
- Локальный список программ читается из реестра без сетевых вызовов. Поиск обновлений запускается отдельной кнопкой. Неопределённый результат не называется отсутствием обновлений.
- Кнопка применения набора реагирует на отметки сразу. Взаимоисключающий выбор установки и обновления не дублируется. Перечень операций виден до подтверждения.
- Понятное сообщение ошибки видно сразу; технические сведения раскрываются по запросу. Результат повторяется только после нового подтверждения.
- Пользовательский архив очищен от исходников, тестов, отладочных символов и отчётов. Исходники доступны отдельно.

Границы проверки:

- Python/API/Chromium проверены в Linux. Демонстрационные проверки не меняют Windows.
- EXE собран для Windows x64. Запуск на Windows, Appx deployment, реальные WinGet-установщики, UAC, Windows Update, дисплеи и звук здесь не испытаны. Это сборка для испытаний, а не подтверждённый стабильный выпуск.
- Требуется интернет для загрузок. Политики организации, отключённый Appx deployment или недоступный GitHub/Microsoft могут блокировать подготовку. Изменение политик для обхода не выполняется.
- Поддерживаются программы из каталога. Драйверы ищутся в Microsoft Update по идентификаторам устройства; наличие пакета для каждого устройства не гарантируется.
- HDR, DPI/масштаб Windows, ICC, DDC, clone/extend и дробные герцовки не добавлены. Масштаб интерфейса самого приложения поддерживается.
- Резервные копии возвращают поддерживаемые настройки; установленные программы и обновления не удаляются автоматически.

Точные проверки и команды: TESTED.md. Ручные испытания: WINDOWS-TEST.md.
