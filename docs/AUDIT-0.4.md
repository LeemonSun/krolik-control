# Krolik Control 0.4.0 — повторный аудит и отчёт

18 октября 2026 · Автор проекта: **LeemonSun**.

**Результат:** исправлены подтверждённые дефекты навигации, сохранения, фокуса, поиска, результата применения и отката. Добавлены повседневные встроенные функции и новый бренд. Сборка включает Windows EXE, встроенный Python и исходники.

**Граница вывода:** это проверенная кодом и интерфейсными сценариями сборка. Запуск EXE на Windows, реальные UAC/установщики, драйверы и физическое оборудование здесь не испытывались. Называть её полностью проверенным стабильным продуктом пока нельзя. Часть расширенных функций из предложений предыдущего аудита остаётся за рамками реализации — они перечислены явно ниже.

## Новые проблемы, найденные при повторном аудите

Каждая строка ниже привела к исправлению, после которого выполнена целевая проверка.

| Находка | Исправление и проверка |
|---|---|
| Возврат сохранённого фильтра снова скрывал результат глобального поиска | Фильтр снимается после восстановления страницы; Firefox доступен из активной группы «Игры» |
| История ломалась при превышении 100 переходов | Добавлено абсолютное смещение; проверены 110 дополнительных переходов и X1/X2 после сдвига стека |
| После перезагрузки страницы стрелки не соответствовали сохранённому пути | Браузерная история восстанавливается вместе со страницами; проверен возврат после reload |
| Масштаб 150% вызывал горизонтальное переполнение | Адаптация рассчитывается по ширине с учётом масштаба; 21 страница, 3 ширины, 4 масштаба в целевых сценариях |
| Повторная полная инвентаризация теряла уже прочитанные возможности программ и автозагрузки | Метаданные этих списков сохраняются при обновлении основной информации |
| Ошибка сохранения могла не дать обновить сведения о реально изменённой системе | Обновление источников запускается и при ошибке сохранения результата |
| Подтверждение поворота считалось ошибкой из-за переставленных ширины/высоты | Проверка результата учитывает исходную и новую ориентацию; отдельный тест портретного режима |
| Временное расположение экранов записывалось до подтверждения | До подтверждения используются временные изменения; тест проверяет отсутствие флагов записи в реестр до ответа |
| Резервные файлы автозагрузки могли оказаться в самой Startup | Резерв расположен за пределами Startup; тест отключения/возврата проверяет реальные временные файлы |
| Наличие Run-значения не гарантировало, что Windows разрешает запуск | StartupApproved только читается; заблокированные/неизвестные состояния становятся доступными для просмотра |
| Крестик окна не всегда доставлял pagehide, процесс оставался жить | Добавлен защищённый поток связи с окном. Проверено закрытие страницы без доставки обычного pagehide: процесс завершился |
| Большая очередь могла превысить лимит keepalive-запроса | При закрытии отправляется минимальное уведомление; обычное автосохранение поддерживает полный ограниченный размер рабочего набора |
| Ошибку отката можно было потерять вместе с резервной копией | Неподтверждённые записи остаются для последующей попытки; тест имитирует недоступный источник |
| Чужой более ранний откат мог перезаписать поздние значения | Возврат разрешён от последней группы к предыдущей |
| Экспорт установленных программ был только отчётом, который нельзя импортировать как профиль | Экспорт теперь выдаёт допустимый профиль с разрешёнными идентификаторами приложений |

## Что проверено

- **137 Python-тестов:** планы и недопустимые значения, источник результата, отказ журнала, отказ сохранения и повтор, межпроцессная блокировка, конфликты записи, откат, точка восстановления, новые функции, безопасность API, таймеры экранов и временное расположение.
- **Полный прогон Chromium:** все 21 страница; ширины 1024/1240/1600, масштабы 100/110/125/150 на рабочих страницах; светлая и тёмная тема; ноль ошибок JavaScript и горизонтальных переполнений в проверенных комбинациях.
- **Сценарии:** X1/X2 через протокол ввода Chromium, Alt+стрелки, сохранение 180 Гц и выбора Steam при переходах, поиск с мешающим фильтром, числовой ввод без потери фокуса, пресеты/отмена, избранное, личные профили, очередь после reload, применение нескольких видов настроек в демо, индикатор микрофона, более 100 переходов.
- **Жизненный цикл:** два отдельных процесса запуска активируют один экземпляр; reload сохраняет сервер и выбранный режим; закрытие окна завершает сервер.
- **Сборка:** официальный embedded Python 3.14.8 сверяется по SHA-256; нативный launcher компилируется под Windows x64 с новым ICO; проверяются структура PE и состав ZIP. Исходники и рабочие файлы сверяются после упаковки.

Демонстрационные уровни звука и устройства являются тестовыми данными, а не измерениями ПК владельца. Скорость настоящего обнаружения, использование памяти в Windows, доступность конкретных герцовок и успешная установка драйвера не выводятся из этих проверок.

## Что осталось

1. **Матрица Windows 10/11:** фактический запуск EXE, обычный пользователь/администратор и отмена UAC, драйверы AMD/NVIDIA/Intel, один/несколько экранов, ноутбук, отключение USB-аудио, потеря интернета, перезагрузка после обновления. Это обязательная проверка перед объявлением стабильного выпуска.
2. **Не реализовано:** extend/clone, точные дробные частоты и предпочтительный режим; управление HDR/DPI/ICC/DDC, FreeSync/G-Sync; устройство звука по умолчанию и микшер приложений; подключение Wi-Fi/Bluetooth. Ссылки на системные окна не выдаются за реализацию этих функций.
3. **Ограничения:** режимы и расположение экранов применяются отдельно; автозагрузка охватывает Run/Startup, а не все задачи/службы/UWP; каталог установленных программ ограничен приложениями из разрешённого списка; Windows Update не содержит всех драйверов производителей.
4. **Упаковка:** portable EXE использует соседнюю папку data. Сертификат подписи издателя не добавлен. Альтернативный однофайловый PyInstaller-сценарий включён в исходники, но не собран и не проверен в этой среде.

## Аватарка и авторство

Сохранено утверждённое название **Krolik Control** и подпись автора **LeemonSun**. Очищенный полный логотип: `assets/krolik-control-logo.png`; прозрачный знак: `assets/krolik-control-icon.png`; Windows-значок: `assets/krolik-control.ico`; копия значка для окна: `ui/brand.png`.

Правка выполнена встроенным imagegen по предоставленному изображению. Суть запросов: сохранить хромированного кролика, бирюзовые глаза, щит и исходные цвета; убрать «01», исправить края и отступы; для значка оставить эмблему на прозрачном фоне без слов и прямоугольной рамки. После генерации выполнено только масштабирование и преобразование в ICO. Точные запросы сохранены в `assets/BRAND_NOTES.md`.
