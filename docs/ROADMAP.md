# Состояние после 0.10.0

20 октября 2026. В коде и автоматических проверках реализован большой набор повседневных задач. Реальная Windows-приёмка остаётся открытой. Исторические планы и аудиты не являются перечнем полностью готовых функций текущего выпуска.

| Направление | Уже реализовано | Следующий критерий готовности |
|---|---|---|
| Выпуск | Setup, portable, локальный runtime, проверка состава/хешей, чистая папка приложения | Чистые Windows 10/11: установка, обновление, удаление, UAC, слабый ПК |
| Интерфейс | 6 групп, поиск, профили, темы, масштаб, X1/X2, сохранение выбора/прокрутки, компактные таблицы | Настоящий DPI и доступность с экранным диктором |
| Программы | Общая модель установок, registry/MSIX, удаление штатным способом, MSI repair, каталог 26 пакетов | Структурированный поиск обновлений вне каталога и проверка реальных установщиков |
| Диски и файлы | Карта папки, крупные файлы, дубликаты, SHA-256, блокировки, транзакционное переименование | Windows: ACL/junction/cloud/съёмные диски, прерывание питания и файловые блокировки |
| Автозагрузка | Run/Startup, сторонние задачи входа/загрузки, подтверждение/возврат задач, просмотр служб | Расширенная матрица прав и дополнительных источников автозапуска |
| Звук | Устройства, сигнал/микрофон, роли, микшер сессий, проверяемый возврат | PolicyConfig остаётся экспериментальным; аппаратная матрица и маршрутизация приложений |
| Экраны | Режимы/поворот/расположение/HDR-WCG, доступность API, отдельный наблюдатель возврата | Windows crash/hotplug, точные дробные режимы, ICC/DDC, перетаскивание схемы |
| Мой ПК | CPU/RAM/диски/DXGI, NVML/ADL, доступные датчики | Несколько GPU и драйверов; CPU-температуры без собственного драйвера не универсальны |
| Сеть | Соединения/владельцы, DNS/TCP/TLS, потери/задержка, Wi-Fi, скорость и узкие исправления | Реальные VPN/прокси/статический IP, Bluetooth и разные сетевые драйверы |
| Диагностика | Базовые бенчмарки, RAM, PresentMon, события/WHEA, NVMe, принтеры/устройства | Реальные таймеры/ETW/датчики; глубокий DPC/дампы и универсальный SMART не реализованы |
| Драйверы | Windows Update, приоритеты, общий хешированный backup и проверка состава | Фирменные пакеты по моделям и проверенное восстановление на оборудовании |
| Перед переустановкой | Читаемые настройки и списки программ, отдельный подтверждаемый кеш установщиков | Перенос между разными ПК; это не полная копия файлов/Windows и не гарантия офлайн-установки |
| BIOS | Только перечисленные доступным OEM-интерфейсом Lenovo/Dell/HP значения | Испытание каждой заявленной модели; универсальные XMP/напряжения ASUS/MSI/ASRock отсутствуют |
| Журналы и отмена | Долговечные ожидания, перечитывание без повтора, общий журнал внешних действий | Полное объединение всех действий/возвратов и сценарии сбоев на Windows |
| Архитектура | Модули новых инструментов, отдельные рабочие процессы, ограниченные результаты | Уменьшить число обёрток функций UI, перейти к общей модели действий и компонентов |
| Подпись и обновления | Сборщик умеет SignTool при наличии настоящего сертификата | Приобрести/подключить сертификат, испытать подпись, подписанный канал и возврат обновления |
