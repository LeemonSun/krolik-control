# Повторный аудит 0.6.0

18 октября 2026 · LeemonSun

## Найдено и исправлено во время работы

1. При подключении нового UI была повторно присвоена const-функция. Ошибку выявил полный браузерный прогон; проверка занятости встроена в исходную функцию.
2. Форматированный дисковый счётчик терял дробные секунды. Задержка теперь считается по разности сырых числителя, базы операций и частоты таймера. При отсутствии операций показатель неизвестен.
3. Суммирование всех GPU-процентов давало бессмысленные значения. Сначала суммируются процессы одного 3D-движка, затем берётся максимальная загрузка движка; показатель ограничен 100% и относится ко всей системе.
4. Старт PowerShell на каждый отсчёт создавал лишнюю нагрузку. Наблюдение выполняется одним процессом с потоком JSON-отсчётов; первое измерение прогревается, фактические времена сохраняются.
5. Неизвестные показатели могли выглядеть как нормальное состояние. Непроверенные устройства/счётчики/аудиосессии отмечаются как недоступные; пустые данные не подменяются нулями.
6. HTTP-соединение включало установление TLS в расчёт скорости. Теперь соединения повторно используются, TLS устанавливается до измерения; неполная загрузка и ошибка HTTP не превращаются в нулевую скорость.
7. Отмена системной команды могла оставить дочерний DISM/PnPUtil. Начатые системные операции завершаются; обычное закрытие ждёт их. Прерываемые проверки владеют собственным процессом и не убивают чужие задачи приложения.
8. Старый отчёт о голосе мог воспроизвести последнюю запись. Воспроизведение связано с ID текущего отчёта; после новой записи/удаления/перезапуска прежнее аудио недоступно.
9. Возврат исправления был недостаточно привязан к истории. Снимок записывается до изменения, откат связан с конкретным отчётом и проверяет текущее значение. Другой/устаревший отчёт не откатывает новое изменение.
10. Копии драйверов используют системную папку Документы с поддержкой перенаправления. Выбор папки восстановления ограничен сохранёнными копиями; ссылки/переходы наружу отклоняются. Windows выбирает совместимые подписанные пакеты.
11. Деинсталлятор сначала содержал весь архив приложения. Теперь он компактный, без вложенной копии runtime. Setup и деинсталлятор имеют значок, manifest и номер версии.
12. Установщик проверяет, что существующая папка принадлежит приложению, что его процессы/файлы закрыты, и что распакованные файлы совпали с манифестом. При неудачном обновлении предусмотрен возврат прежней папки. Манифест целостности не заменяет цифровую подпись издателя.
13. Для управляемого компьютера обнаруженный запрет микрофона политикой не предлагается обходить изменением пользовательского разрешения.
14. В обычном интерфейсе убраны названия внутренних алгоритмов и команд; методика остаётся в отчёте/подробностях. Добавлено отключение анимаций и учёт системного уменьшения движения.

## Практические пределы

Физические неисправности, звук из реальных динамиков, FPS/frametime игры, температуры и троттлинг не определяются автоматически этим набором проверок. Пользователь подтверждает слышимость сигнала; причины просадок оцениваются по доступным наблюдениям с обозначением вероятности. Бенчмарк не заменяет длительный тест стабильности, проверку RAM или профессиональный игровой benchmark.

Скорость зависит от доступности Cloudflare и проверяемого маршрута. В этой Linux-среде живое обращение к серверу скорости завершилось тайм-аутом; цифры не выдавались. Протокол и обработка неполных/ошибочных ответов проверены подменами, UI — демоданными. На пользовательской сети ещё нужны испытания.

Windows x64 EXE скомпилированы. Реальный запуск Setup, обновление/удаление, системные вызовы и измерения на оборудовании в Linux не выполнены. Это существенный оставшийся этап, подробно описанный в WINDOWS-TEST.md.
