# Приёмка 1.0: 100 сценариев

Статус: **ожидает выполнения на настоящих Windows**. Linux-автотесты не заполняют эти пункты автоматически. Для каждого случая записать ОС/build, версию приложения, оборудование, шаги, ожидаемый/фактический результат и ссылку на локальный журнал. Отказ/не реализовано не равны «пройдено»; неприменимость требует причины.

Матрица: чистые Windows 11 и Windows 10 x64; обычный пользователь и UAC; один/несколько экранов и GPU; встроенное/USB-аудио; хотя бы по одному заявленному OEM. Изменения BIOS и сбои проверяются отдельно на предназначенном для испытаний ПК с владельцем. Не применять все изменения подряд к основному компьютеру.

- [ ] KC-003: Setup устанавливает в профиль пользователя; запускаются ярлыки и основной EXE.
- [ ] KC-004: Повторная установка обновляет программу, сохраняет пользовательские данные.
- [ ] KC-005: Отказ записи ярлыка/регистрации возвращает прежние файлы и регистрацию.
- [ ] KC-006: Второй Setup не меняет одновременно выполняющуюся установку.
- [ ] KC-007: Удаление убирает файлы приложения/ярлыки/регистрацию; чужие файлы не удаляются.
- [ ] KC-008: Пути с кириллицей/пробелами, ограниченные права, Defender и SmartScreen дают понятный результат.
- [ ] KC-009: Второй запуск активирует первое окно; reload не закрывает backend.
- [ ] KC-010: Закрытие окна завершает принадлежащие приложению процессы; занятая операция корректно завершается/отменяется.
