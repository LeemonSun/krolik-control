# Krolik Control 0.7.0 — «Мой ПК»

19 октября 2026 · Автор проекта: LeemonSun

## Добавлено

- Отдельная вкладка «Мой ПК», доступная из навигации и поиска. Сохраняются последнее место, прокрутка и раскрытые сведения.
- Схема подключённых экранов, основного выхода звука и микрофона. Переход к настройке конкретного экрана, звука и ввода. Колонки/наушники/цифровой выход различаются по свойству Core Audio FormFactor; при неизвестном типе используется нейтральный значок.
- Компактная локальная библиотека SVG: процессор, дискретная/встроенная графика, память, накопитель, плата, монитор, корпус, наушники, колонки и микрофон. Никаких загрузок изображений при запуске. Это схемы типов устройств, не фотографии конкретной модели.
- Модели CPU/GPU, ядра и потоки, состав и частота модулей RAM, плата, физические накопители и локальные фиксированные тома.
- CPU и память через Win32; GPU — агрегат доступных 3D-движков Windows. До 45 последних отсчётов в памяти, обновление интерфейса примерно раз в две секунды. Пропуски в измерениях не превращаются в нули.
- Температуры CPU/GPU из доступного работающего WMI-провайдера Libre Hardware Monitor или Open Hardware Monitor. Встроенной установки этих компонентов нет. Зоны ACPI не выдаются за CPU. Для нескольких GPU нагрузка подписана как общесистемная, температура — как максимум доступных датчиков.
- Свободное место на разделах; доступные температура, израсходованный ресурс и неисправленные ошибки физических дисков. Недоступное состояние не окрашивается как доказанная поломка.
- По запросу: ошибки/критические события Windows за неделю и причины пробуждения/удержания от сна. Эти проверки ничего не исправляют и не меняют в Windows.
- При пустой очереди на «Мой ПК» скрыта ненужная панель применения. При наличии выбранных настроек панель остаётся доступной.

## Исправлено по аудиту

1. Профиль с приложениями больше не пропускает их только из-за отсутствия WinGet: официальный компонент подготавливается обычной очередью после подтверждения. Сохраняется проверка поддерживаемой сборки и известных приложений.
2. Ошибка сканирования устройств видна вместе с повтором. Пустой успешный результат, первое определение и ошибка теперь имеют разные сообщения; предыдущий список не очищается при ошибке чтения.

## Ограничения и ресурсы

- «Мой ПК» не запускает мониторинг до открытия вкладки. После ухода/скрытия страницы запросы прекращаются; сборщик завершает работу по аренде примерно за 8–10 секунд. При применении настроек или запуске центра диагностики мониторинг приостанавливается.
- Статический состав ПК читается фоном; повторное чтение ограничено по частоте. Отказ чтения сохраняет предыдущие сведения. Обновление устройств перечитывает экраны и аудиовыходы.
- Показатели и графики не записываются непрерывно на диск, служба и автозагрузка не устанавливаются. Один процесс PowerShell работает только во время активного мониторинга; его завершение привязано к сборщику и закрытию приложения.
- Температуры и счётчики могут быть недоступны на конкретном ПК. Показатели стареют с видимой отметкой; чисел «для красоты» нет. Примеры значений существуют только в явно обозначенном деморежиме.
- Не используется 32-битное поле WMI AdapterRAM как достоверный объём видеопамяти современных карт.
- Запись события о неожиданном выключении не считается доказательством неисправности БП; отсутствие доступных событий не считается доказательством исправности ПК.

## Проверка

- 243 модульный тест: все прошли. Новые проверки охватывают закрытие одновременно с запуском процесса, запрет запуска после закрытия, начало/остановку сбора, одноразовый запуск потока, отсутствие запуска во время операции, отказ чтения с сохранением предыдущих данных, Win32-расчёт CPU/RAM, валидацию датчиков и авторизацию нового API.
- Отдельный браузерный сценарий: схема и комплектующие, изменение типа выхода на наушники, портретный экран, отсутствующие устройства, видимость очереди, отсутствующие датчики, обновление без сброса прокрутки/раскрытых деталей, обе регрессии аудита, отчёты событий/сна, восстановление вкладки, 600–1440 px и масштаб 100–150%, отсутствие запросов со скрытой вкладки.
- Общий прогон интерфейса: все страницы, профили, боковые кнопки мыши, поиск, сохранение выбора, применение и длинная история переходов — без ошибок JavaScript и переполнения.
- Дополнительно: care-ui, apps-ui, audit-ui, reliability-ui и lifecycle — проходят.
- Синтаксис трёх новых PowerShell-сценариев проверен официальным PowerShell 7.6.7 в Linux. Исполнение этих сценариев в Windows и совместимость с Windows PowerShell 5.1 нужно подтвердить отдельно.

## Что ещё требует настоящей Windows

Setup/portable на чистых Windows 10/11 x64, Core Audio FormFactor реальных устройств, Win32-счётчики, запуск/остановка процесса мониторинга, провайдеры датчиков разных производителей, USB/HDMI-аудио, несколько GPU, USB/RAID-накопители, доступность журналов и powercfg без/с правами администратора.

Тесты в Linux, демонстрационные данные и проверка синтаксиса не заменяют этих испытаний. Выпуск не имеет доверенной подписи издателя и не заявляется как проверенный на всех Windows-ПК.
