# Повторный аудит Krolik Control 0.6.2

18 октября 2026 · Автор проекта: LeemonSun

## Найдено и исправлено

| Проблема | Исправление |
|---|---|
| После завершения операции без изменения значения поля оставались заблокированными | Убраны три независимых блокировки. Временные ограничения снимаются централизованно; исходно недоступные поля сохраняют ограничения |
| Значение аудионастройки могло измениться, пока готовился список подтверждения | Для проверки и применения используется отдельная копия выбранного набора |
| Быстрые нажатия могли заменить открываемое подтверждение другим набором | Одновременно готовится одно подтверждение; повторные запросы не подменяют первый |
| Запоздавшее подтверждение открывалось после перехода в другой раздел | Результат проверки связан с конкретным переходом; устаревший ответ игнорируется |
| Немедленное применение удаляло другую настройку того же устройства из очереди | Из очереди и сохранённого черновика удаляются только совпадающие успешно выполненные значения: звук, яркость, экран, языки, расположение и автозагрузка |
| «Повторить ошибки» могло не сработать сразу после завершения | Повторное чтение состояния резервируется до публикации завершения. Убрано окно, когда интерфейс уже разрешал действие, а фоновая проверка ещё только запускалась |
| Неизвестные результаты DNS/HTTPS выдавались за исправное подключение | Неполная диагностика отмечается отдельно; успешный вывод требует подтверждённых проверок |
| Повреждённый сохранённый отчёт с неверным типом поля мог остановить запуск | Проверяются структура, типы, идентификаторы, числовые значения и объём. Повреждённый результат пропускается с понятным уведомлением |
| Несколько новых повреждённых файлов скрывали исправные старые результаты | Загружаются до восьми корректных результатов из ограниченного набора последних файлов |
| Сетевое исправление автоматически показывалось на вкладке звука | Исправление связано с исходным разделом. Старые результаты остаются доступны через ручной выбор |
| Список показывал выбранный результат, которого не было на странице | При отсутствии результата для вкладки выводится «Выберите результат» |
| После отката исправления оставалась кнопка повторного отката | Состояние и сохранённый отчёт обновляются; кнопка связана с актуальной резервной копией. Отменённое исправление помечается |
| Отменённая или неудачная запись могла остаться в памяти без доступного отчёта | Аудиобуфер и ссылка на запись очищаются при отмене и ошибке |
| Нечисловой результат бенчмарка мог нарушить передачу состояния | NaN, бесконечность и логические значения не считаются измерением |
| Диски с разными целевыми путями сравнивались как одинаковые | Для сравнения дисковых результатов должен совпадать целевой путь |
| Неудачная первая установка оставляла неполную папку | Незавершённая папка удаляется и при первой установке |
| Ошибка обновления могла вернуть старые файлы с новыми ярлыками или записью удаления | До изменения сохраняются значения реестра и байты ярлыков; при неудаче они восстанавливаются вместе с прежней папкой |
| Двойной запуск установщика мог начать две операции над одной папкой | Добавлена блокировка установки/удаления для текущего пользователя в сеансе |
| Промежуточный portable-архив мог остаться неполным при прерывании записи | Архив формируется отдельно, закрывается, проверяется и публикуется заменой файла; после сборки сверяется его наличие внутри Setup |

Зависимости программы не добавлены. Исправления 0.6.1 для выбора аудиоустройств, прокрутки, выделения текста и кратких подписей сохранены.

## Проверки

- 232 Python-теста прошли. Включены проверки повреждённых отчётов, ложного успеха диагностики, отмены записи, отката, сохранения разных отложенных значений и резервирования повторного чтения состояния.
- Отдельный браузерный сценарий: 10 новых проверок блокировок, неизменяемого подтверждения, повторных нажатий, сохранения очереди, ошибок подготовки подтверждения, поздних ответов, категорий результатов и настоящего неудачного задания на тестовом backend.
- Основной интерфейс: 22 страницы; ключевые экраны при 3 размерах окна × 4 масштабах.
- Повторены сценарии звука/прокрутки/выделения/перезапуска, диагностики, установки программ с отказом и повтором, второго запуска и закрытия приложения.
- Транзакция установщика: успешная первая установка; отказ записи регистрации с удалением частичных файлов; отказ создания ярлыка при обновлении с точным возвратом старых файлов/регистрации/ярлыков; одновременный запуск двух установщиков.
- Синтаксис JavaScript и 14 сценариев PowerShell проверен. Установщик разбирается актуальным PowerShell parser; это не исполнение Windows PowerShell 5.1.
- Контроль сборки Windows x64: совпадение файлов с исходниками, SHA-256, PE-ресурсы и версия, вложенный пакет Setup и целостность ZIP.

## Что ещё требует Windows

Интерфейс проверялся в Linux/Chromium с демонстрационными данными и тестовыми подменами. Транзакция установщика выполнялась в изолированной папке под PowerShell с подменами реестра, COM-ярлыков и определения Windows-процессов. Эти проверки подтверждают логику переходов и отката, но не доказывают совместимость настоящего реестра/COM и установку на Windows.

В этой среде не запускались готовые Windows EXE и настоящий Setup. Нужны испытания установки/обновления/удаления на чистых Windows 10/11, реальных звуковых устройств, дисплеев, UAC, WinGet/Windows Update и измерений на оборудовании. Исполняемые файлы остаются без доверенной подписи издателя. Это проверенная автоматическими сценариями сборка с указанными пределами, а не гарантия отсутствия всех ошибок.
